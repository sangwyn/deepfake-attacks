# Отчёт по кампании

`report_ru.pdf` — результаты development-прогонов: постановка, шесть методов,
матрица переноса, выводы и оговорки. Собирается из `report_ru.tex` командой
`xelatex report_ru.tex`.

`development-results.json` — первичные числа, из которых построены таблицы.
Каждая строка извлечена из `summary.json` прогона, чей `verification.json`
содержит `outcome: passed`. Прогоны на восьми изображениях (`smoke`) в отчёт не
входят: там разница между соседними значениями составляет одно изображение.

Пересобрать выгрузку из завершённых прогонов:

```bash
.venv/bin/python scripts/collect_results.py
```
