# Первичные артефакты development-прогонов

Двенадцать прогонов по 100 изображений, по одному каталогу на эксперимент. Имя
каталога — `experiment_id`, в нём закодированы атака, источник градиента,
масштаб и сид: `ssa-vit-development-seed0` это SSA, градиент от ViT,
development, сид 0.

Каждый прогон имеет отчёт верификатора с `outcome: passed` и ноль нарушений
бюджета. Это копии из `tracking/runs/` на сервере, приведённые к плоской
структуре для чтения и цитирования.

| Файл | Что в нём |
|---|---|
| `summary.json` | итоговые числа: ASR по каждому детектору, SSIM, LPIPS, время |
| `verification.json` | вердикт детерминированного верификатора |
| `per_sample_metrics.jsonl` | строка на изображение: L∞, SSIM, LPIPS, предсказания до и после |
| `norm_audit.json` | проверка бюджета по перечитанному с диска PNG |
| `provenance.json` | коммит, хеши весов и манифеста, версии пакетов, режим детерминизма |
| `resolved_config.yaml` | замороженный конфиг прогона |
| `selection.jsonl` | какие изображения отобраны и какие прошли отбор по clean-correct |

Направление читается двумя полями: `source_model` в `summary.json` — детектор,
от которого взят градиент; ключи внутри `per_model` — детекторы, на которых
измеряли. Совпадают — белый ящик, различаются — перенос.

Состязательные изображения сюда не входят: они лежат вне репозитория, в
`/home/aiattacks/oleg/aadd-attack-runs/`, и адресуются хешем конфига.

Прогоны на восьми изображениях (`smoke`) не включены: там разница между
соседними значениями составляет одно изображение.
