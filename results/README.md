# Retained results

- `five_directions/` contains the concise 100-image comparison used to select
  the submission candidate.
- `development/` contains twelve verified 100-image baseline/transfer runs and
  their aggregate summary.
- `detector_validation/` records the historical clean-detector check.
- `legacy/` preserves the pre-campaign I-FGSM result.

These are immutable historical measurements. They use local detectors and are
not claims about a hidden detector or an official leaderboard score. Generated
adversarial images were intentionally kept outside Git.
